# Create an issue

Use this route only when the user explicitly asks to create, file, open, or
publish exactly one new tracked issue.

Read the repository `AGENTS.md` and locate its configured issue-creation
workflow. Read that project-specific skill completely and follow it. It owns
the tracker provider, title and label taxonomy, description format, approval
boundary, issue creation command, and readback verification.

If the repository does not configure an issue-creation workflow, stop and
report the missing configuration as the blocker.

After reporting the created issue and its readback, stop. Delivery, planning,
and additional issue mutations require a separate human invocation.
